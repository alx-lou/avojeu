# Avojeu

Avojeu is a small web app for managing games, players, and sessions with friends. It brings together a few game pages and shared tools to make group play easier.

## What it includes

- Game pages for games like Flip7, and Codename
- Player management and session tracking
- Shared utilities such as timers, dice rolls, score tracking, and team sorting
- A simple interface built with React and Vite

## Project structure

This project is a frontend app using React, TypeScript, and Vite. The app organizes games and tools in a small component-based structure.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build for production

```bash
npm run build
```

## Preview production build

```bash
npm run preview
```
